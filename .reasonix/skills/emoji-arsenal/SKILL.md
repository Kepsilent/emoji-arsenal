## 概述

智能表情包系统 —— 根据对话情绪自动匹配表情包，支持本地缓存 + 联网搜索，高频使用自动缓存。

9 种情绪识别（开心/难过/爱/生气/惊讶/可爱/赞同/再见/爆笑），多样性轮换，智能升温降级。

---

## 使用方式

```
/emoji-arsenal
```

或直接调用 Python API：

```python
from emoji_matcher import match
result = match("好开心啊哈哈哈")
```

---

## 执行指令

### 情绪检测 → 匹配表情包

1. 用户发送消息
2. 提取情绪关键词
3. 优先查本地 stickers/ 库
4. 未命中则联网搜索（百度图片）
5. 发送图片 + 自动缓存

### 缓存策略

| 层级 | 触发 | 清理规则 |
|------|------|---------|
| bundle | 初始内置 | 永不清理 |
| hot | 使用 ≥3 次 | 60天未用降级 |
| temporary | <3 次 | 30天未用删除 |

### 依赖

- Python 3.8+
- jieba（中文分词）
